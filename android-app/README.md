# Android app skeleton for lu-bi-si

This directory contains a minimal Android project skeleton you can open in Android Studio.

How to open
1. In Android Studio: File → Open... → select the `android-app` directory.
2. Let Android Studio sync Gradle and download dependencies.
3. Run the app on an emulator or device.

What is included
- settings.gradle.kts and basic Gradle configuration
- app module with a simple Compose-based MainActivity showing a product list (mock data)
